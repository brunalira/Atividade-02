# CheckMeuCarrinho

Aplicativo Android feito em Java para simular uma lista de compras com 5 produtos.

O usuário pode marcar os itens que deseja comprar e o app mostra o valor total no final.

---

## Produtos

- Arroz 1kg – R$ 2,69  
- Leite longa vida – R$ 2,70  
- Carne Friboi – R$ 16,70  
- Feijão carioquinha 1kg – R$ 3,38  
- Refrigerante Coca-Cola 2L – R$ 3,00  

---

- CheckBox  
- Button  
- TextView  
- Java + XML  
- Separação dos textos no `strings.xml` e cores no `colors.xml`
